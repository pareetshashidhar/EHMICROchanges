Mandatory Invariant Rules

These foundational defenses are permanent and cannot be bypassed:

  • • Path Traversal Defense: Rejection of .., slashes, and reserved Windows device names.
  • • Zero-Byte Rejection: 0-byte uploads are unconditionally blocked.
  • • Signature Mismatch: Declared extensions conflicting with header magic bytes are blocked.
  • • Disguised Executables: Double extensions with executable segments (e.g. .pdf.exe) are intercepted.
  • • Storage Segregation: Rejected files NEVER enter accepted storage under any circumstances.

Storage Vault Security

Uploaded files are given random UUID names and stored outside the public document root (instance/).

Files are non-executable, not indexed by web servers, and cannot be accessed via direct public URLs.
